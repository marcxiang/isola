Isola 0.5.1 — macOS 本地浏览器环境与运营计划管理

公开源码说明
本文件保留 0.5.1 及更早版本的历史使用说明。当前源码为 0.5.3-dev.1；最新进度以 README.md、HANDOFF.md、CHANGELOG.md 与 DEVELOPMENT.md 为准。0.5.2 已完成真实照片上传及单次 TEST 发布；当前回执关联仍在开发，后续消息/交易尚未联调。下文“本版本/当前”指当时的 0.5.1 历史状态。

本版本状态
鼠标点击/滚动提示、货盘同步和各环境计划已加入。0.5.1 新增真实商品资料核对、打开对应环境刊登页及逐字段填写回读。已登录的法国站刊登页经过人工观察；已验证真实标题、描述的填写；其他字段的实页验证结果见测试报告。
真实 Vinted 法国站的发布提交、消息回复、接受报价、获取面单和货盘采购尚未完成联调。正式应用在业务任务入口统一阻止这些操作，任务会保留为待核对；勾选自动功能或启动调度不会解除此限制。当前版本不能用于正式无人值守经营。

运行方式
1. 使用 Node.js 24，在源码目录执行 npm ci，再执行 npm start；或用 npm run package 构建 macOS 应用。默认构建面向 Apple Silicon（M 系列 Mac）。
2. 新建环境，填写名称和启动网址。默认推荐“本机原生”，使用当前 Mac 的设备参数；需要手动设置时选择“自定义参数”，再配置语言、时区、视口及代理。
3. 保存后启动。每个环境使用独立、持久化的 Chromium Session。
4. 浏览器顶部“指纹自检”会在本地读取当前页面的实际指纹值，不连接检测网站。

已实现
- 环境新建、编辑、搜索、分组、备注、复制配置、删除和浏览数据清理。
- 独立 Cookie、LocalStorage、IndexedDB、缓存及认证会话；环境关闭后保留。
- 多标签浏览、地址栏、前进/后退/刷新、弹窗在同环境新标签打开。
- 批量启动和关闭；启动中的环境会锁定配置。
- 本机原生模式保留实际语言、时区、CPU、屏幕、像素比和 GPU；宽高用于初始窗口大小。
- 自定义模式支持 UA、语言、时区、视口/屏幕尺寸、CPU 逻辑核数配置。
- HTTP、SOCKS5 代理，包括用户名/密码认证。
- 代理出口 IP 与延迟检测；代理连接失败不会配置 DIRECT 回退。
- SOCKS5 认证通过只监听 127.0.0.1 的临时 HTTP 桥接处理，环境关闭时释放。
- 代理密码通过 macOS 系统 safeStorage 加密保存，不返回管理页面明文。
- JSON 配置导入/导出。导出不包含代理用户名/密码，也不包含 Cookie/浏览数据。
- 本地诊断日志和配置备份。

代理使用
- HTTP：填写主机、端口，按需填写用户名和密码。
- SOCKS5：支持无认证和用户名密码认证；目标域名交给 SOCKS5 代理解析。
- 编辑环境时，密码留空表示保留；勾选“清除已保存的代理密码”可清除。
- “检测出口 IP”访问 https://api.ipify.org?format=json；检测服务故障也会导致检测失败。
- WebRTC 使用 disable_non_proxied_udp，QUIC 已禁用。未对所有网络协议、DNS 和第三方网站完成泄漏审计。

数据位置
~/Library/Application Support/Isola/
profiles.json 保存环境配置（代理密码为密文）；profiles.json.backup 保存上次配置。
Partitions/ 保存环境的 Chromium 数据。配置导出不等于浏览数据备份。
复制整个数据目录前应完全退出应用。加密密码依赖当前 macOS 用户的系统密钥，不能保证跨机器恢复。

功能边界
这是可运行的本地 MVP，不是 BitBrowser 或 AdsPower 的完整替代品。
自定义指纹通过 Chromium 调试协议作用于标签页；本机原生模式不应用这些参数覆盖。没有修改 Chromium 原生内核。
Canvas、WebGL、AudioContext、字体、设备标识和 TLS 指纹保持系统/Chromium 默认值。
自定义模式的 Worker、嵌入页面、Client Hints 等上下文不保证与页面设置完全一致。本机原生模式已检查主页面、独立/共享/Service Worker、同源与跨域 iframe 的关键参数；共享/Service Worker 的语言列表仍可能不同，检测异常会保留在报告中。
不提供“不可关联”“无法检测”或绕过网站风控的保证。
相机、麦克风、地理位置等网站权限当前默认拒绝；暂未做站点权限管理。
未实现浏览器扩展管理、书签、云同步、团队权限、账号托管、外部自动化 API、内核更新器及商业授权系统。
当前为本地开发包，未做 Apple Developer ID 签名或公证，也未在 Intel Mac 上实机验证。

0.3 新增：AI 页面控制
在环境浏览器顶部点击“AI 控制”，打开助手；点击“设置”填写服务地址、模型和 API Key。
- OpenAI 新模型优先选择 Responses 协议，地址默认 https://api.openai.com/v1。
- 兼容服务可选择 Chat Completions，地址填写服务的 API 基础地址（通常以 /v1 结尾）。
- 本机兼容服务可以使用 http://localhost:端口/v1，无需 Key；远程服务必须使用 HTTPS。
- 模型须支持 function calling。模型名称由服务提供商决定，应用未内置或附赠模型额度。
- 输入自然语言任务后点击开始。支持读取当前页、点击控件、替换输入文字、按键、滚动和导航。
- AI 仅控制启动时的标签页。你切换标签或通过工具栏/地址栏导航时，任务会停止。
- 面板可以收起，任务会继续；顶部仍保留停止按钮。操作记录只在本次运行的内存里保留。
- 提交、删除、支付等控件以及访问新站点会要求确认；密码、支付凭据、验证码和文件上传需手动处理。
- Key 用 macOS safeStorage 加密保存于 ai-settings.json，不返回页面明文。更换服务地址后要重新填写 Key。
- 运行任务会把页面可见文字、控件标签和任务发送给配置的模型服务。不会读取输入框已有值，不自动发送截图。
- 模型请求通过系统网络，网页流量继续使用对应环境的代理。

自动控制痕迹的处理与边界
控制使用现有 Chromium 内部接口，不启动 WebDriver，不开放额外远程调试端口，不在网页 DOM 上添加控件属性或控制面板。
页面读取在隔离的 JavaScript world 中进行；测试中主世界没有控制对象，点击和输入事件 isTrusted 为 true，navigator.webdriver 保持 false。
未伪造这些检测属性，也不能保证网站无法识别自动行为。访问节奏、账号行为、浏览器内核差异等仍可能被识别。
当前工具主要支持顶层 DOM；iframe、封闭 Shadow DOM、Canvas 页面、拖拽和复杂原生选择器尚不完整。
实际 API 调用需要你提供可用服务和 Key。开发验证使用本地模拟模型，未使用你的真实模型账号。

0.3.1 更新：设备一致性与操作可靠性
- 新环境默认“本机原生”；旧环境继续使用原来的自定义参数，避免悄悄改变已有环境。
- 如要切换旧环境：关闭环境→编辑→环境模式选择“本机原生”→保存→启动。
- 指纹自检新增原生 webdriver getter、控制标记、Worker/同源 iframe 一致性、Canvas 诊断校验值与字体宽度检测。检查只在本地进行。
- 修复跨域 iframe 使用带产品名 UA 的问题，HTTP Accept-Language 与本机页面首选语言保持一致。
- 修复认证 SOCKS5 的 IPv4/IPv6 目标编码、握手超时与关闭时的待完成连接清理；代理域名统一大小写。
- 修复 WebRTC 策略配置位置，使用受支持的运行时 API 并读取 getter 验证。
- 下拉菜单优先展示当前选项；支持展开的嵌套类别和开放 Shadow DOM；可点击区域被局部覆盖时选择实际可见位置。
- 支持 Esc/Return/Down/Ctrl+A/Cmd+A/Shift+Tab 等按键别名及短序列；原生编辑命令避免应用菜单截获。
- 临时遮挡会短暂等待；持久遮挡、只读、禁用或已重新渲染的控件会给出具体原因和最新页面状态；相同阻塞连续三次后停止。
- 加强密码/支付凭据/OTP/上传控件的键盘边界；Enter/Space 激活敏感按钮也要确认；确认期间焦点改变会停止操作。
- 脚本跳转到新来源时，在读取该新页面交给模型前要求确认。跳转网络请求可能已经发生，此确认不等于阻断网络跳转。
- iframe 或不可读取组件中的键盘操作需手动处理。敏感操作标签识别覆盖中文、英语及常见法语词，但不能识别所有自定义控件语义。
- 公开检测页是一次性诊断样本；检测页通过不代表 Vinted 或其他网站一定认定为真人。结果及未验证项请查看同目录的设备检测报告。

进一步验证
ISOLA_PUBLIC_AUDIT=1 npm run test:electron 会在临时环境访问 bot.sannysoft.com 和 browserleaks.com/javascript，并保存观察结果。默认回归测试只使用本地站点。
TLS、全部 DNS/IPv6/代理泄漏、真实商业代理、Vinted 账号行为与风控未完成全面验证；不能据此声称“所有检查通过”或“无法识别 AI”。

0.4.0 更新：可见、可暂停的 AI 页面控制
- 新增实时操作卡：目标控件名称、页面位置、阶段、操作步数、模型与耗时。历史记录显示每一步及页面变化。
- 点击和输入前以浏览器原生覆盖层短暂高亮目标；不向网页 DOM 插入控制面板。
- 暂停会取消等待中的模型请求；正在执行的单次页面操作结束后暂停。可亲自操作当前页面，再继续，继续时重新读取页面。切换标签或通过工具栏导航仍会停止任务。
- 页面信息补充控件分组、焦点、选中状态、必填/无效状态、弹层提示和滚动位置；支持指定分类菜单内部滚动。
- 操作后等待页面短暂稳定，核对可见变化；填写后只回传是否与本次输入一致，不回传原有值。模型准备结束时再读取页面核对结果。
- 相同操作反复失败或连续没有可观察变化时停止，避免无效循环；模型批量返回操作时只执行第一项，后续需重新决定。
- 对短暂的 429/502/503/504 服务错误最多重试两次；压缩旧页面快照，图片仅保留最近一张供下次请求使用。
- 可在 AI 设置打开“视觉辅助”，默认关闭。需所选模型同时支持图片输入与 function calling；Responses 和 Chat Completions 均已适配。
- 视觉辅助发送经过遮盖的截图：输入框、可编辑区域、iframe、Canvas 等区域会遮盖；其他可见文字和图片仍会发送给所选服务。不能保证消除页面上所有私人信息。
- 视觉辅助限于可以核对截图坐标的页面；建议本机原生模式、100% 缩放。自定义视口不匹配、布局正在移动或出现无法检查的封闭组件时，会提示并回退文字控制。
- API key 设置和原来的环境、Cookie、代理配置继续保留。应用使用相同的数据目录，升级前请退出旧版本，避免单实例把新窗口转交给旧版本。
- 本轮使用本地模型模拟服务验证协议和操作恢复，没有调用真实付费模型。模型实际理解能力和任务效果仍取决于所选模型与目标网页，不等同于成熟通用电脑助手的全部能力。

0.5.0 更新：可见鼠标操作与货盘运营工作台
- AI 点击和输入现在显示蓝色指针、目标边框及点击波纹；滚动显示方向箭头，页面分成短步滚动。操作提示属于应用窗口，不插入所访问网页。
- 提示仅在当前活动浏览器窗口位于前台时显示；切换窗口、隐藏或最小化后隐藏。它展示 AI 的目标位置，不代替 macOS 系统鼠标，也不记录手工鼠标轨迹。
- 环境管理主页新增“运营工作台”，包括运营概览、上架计划、货盘与图片、任务记录、连接与规则。
- SKU Desk 1.8 默认地址为 https://sku.meetist.fr/api/v1。API Token 用 macOS safeStorage 加密保存；留空保留原 Token，勾选清除可移除。先保存设置，再“检查已保存的连接”，然后“同步货盘”。连接/同步是只读请求，不领取图片、不下单。
- 商品目录显示 SKU、库存、货盘采购价、可用图片套数；图片套组状态依货盘响应展示。缺失或未知数据不会当作库存充足、零价或可用照片。已使用配置的连接核对商品和图片只读接口；其他业务权限仍待验证。
- 每个计划绑定一个浏览器环境和一个 SKU，可设置累计销售目标、上架价、最低接受价、复用自己图片的选项、回复说明和自动回复/报价开关。金额为 EUR，最低接受价必须大于零且不高于上架价。
- “累计销售目标”按确认付款成交累计。例如目标 5 表示逐件销售补充至 5 件；每个环境、每个 SKU 同时只保留一个在售记录，不是一次发布 5 条相同商品。此流程规则已用本地模拟场景验证，尚未连接真实 Vinted 页面。
- 流程引擎会核对商品、图片、价格、账号和平台回执；接受报价本身不视为付款，不据此采购。采购前还须核对已付款订单、买家、面单所属订单、数量、库存、采购总额和金额上限。以上业务动作在正式应用中仍全部保持未启用状态。
- 照片领取和货盘下单使用持久化的固定幂等编号；写入结果不明确时保留为“待核对”，不换新编号创建第二单。WMS 只有 submitted 才是已确认接单；HTTP 200 不等于仓库接单。
- 运营状态保存在 ~/Library/Application Support/Isola/commerce/commerce-state.json。密钥和预备采购文件内容加密；计划、目录、任务与业务记录保存在本机，并非整个文件都加密。不要把该目录当作可公开分享的日志。
- 多环境调度每个环境同一时刻执行一个任务；可设置同时执行 1–3 个环境。所有 SKU 请求共用每 60 秒最多 100 次、完整请求最多 3 并发的限流器，包含响应下载与清理过程。
- 单笔、每日采购上限默认均为 0，表示未授权自动采购。每日按法国时区累计，包含结果尚未核对的采购预留。金额上限不是开启真实业务执行的开关，真实流程验证仍需完成。
- “允许后台持续调度”开启后，关闭管理窗口/工作台会隐藏窗口；退出应用仍会停止。对应浏览器环境需要保持打开。后台需要应用存活、电脑清醒且网络可用；系统睡眠会暂停调度，唤醒或重启后须核对任务再手动启动，不承诺全天候服务。
- 重启恢复时，上次未完成的外部操作进入待核对，不自动重放。磁盘写入失败会停止后续外部操作，防止无法记录结果时继续运行。

0.5.1 更新：刊登资料核对与页面准备
- 修复关闭/刷新有未保存内容的页面时缺少确认的问题，默认保留；加载中的停止按钮持续可用，页面延迟关闭后清理失效标签。
- 手动点击“填写页面”会展示对应窗口和原生操作提示，便于观察；后台调度不会因此获得新的发布或采购权限。
- 上架计划新增法语标题、描述、分类路径、成色、品牌、尺码、颜色和包裹规格。按事实填写，不会从笼统商品名猜测。
- “打开刊登页”启动对应环境，优先显示已有的新商品页，否则新增标签；不覆盖其他标签的内容。
- “核对资料”只读取计划对应的商品详情、全部图片套组与该环境当前页面，核对商品编号、SKU、库存、图片归属及缺失信息。
- “填写页面”仅在法国站全新刊登页准备明确提供的标题、描述、分类、成色、品牌、单一颜色、价格及 Petit / Moyen / Grand 包裹选项，每步读取结果核对。已选包裹只核对，不重复点击；不推断尺寸重量。尺码和照片上传尚待实现；不会点击保存草稿或发布。
- 品牌菜单与精确搜索结果会限时等待；价格输入框可识别推荐价出现后扩展的标签。选项不唯一、菜单未关闭或页面持续变化时停止，不猜测下一个点击目标。
- 已有非空草稿或手工改动不会被自动覆盖；中断、切换标签、页面导航会停止填写。读取超时 30 秒，整次字段填写超时 120 秒；超时后须核对当前页面。
- 仅对确定从未提交过的待核对/已取消任务提供“重试原任务”。保留原编号；已提交、结果不明确或旧销售周期不能直接重试。
- 未提交的暂停计划可以补充资料；有业务历史的计划不能换绑商品/环境。已付款销售入账与后续任务一次落盘，避免中断导致漏记或重复计数。
- 本地固定网页的真实 Electron/CDP 联调覆盖可信输入、5,00 价格格式、分类单选、重复填写、已有草稿、导航与中断保护；这些测试不等同于真实网站发布/成交验证。

当前尚待验证的部分
当前正式 Vinted 适配器在 requireReady 阶段直接停止任务，消息/交易轮询也尚未接入。所有刊登、回复、报价、面单和采购的流程测试使用本地固定场景或模拟接口，不代表已在 Vinted 和真实货盘完成端到端验证。
已完成实际货盘连接与测试商品 TEST 的商品、库存、照片套组只读同步。采购限额仍为 0。下一步需完成商品字段、照片上传、发布回执、消息、报价、已付款订单及面单验证；采购总费用的可靠来源也须确认。
