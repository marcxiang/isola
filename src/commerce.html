    VINTED / CURRENT SESSION

    核对当前登录账号

    请先在这个固定环境中完成登录或验证码，并确认当前窗口登录的就是以上账号。点击确认后，应用会读取当前账号菜单并保存核验身份；不会提交登录表单。
    VINTED / ACCOUNT

    删除本机账号记录

    这会删除该账号的本机记录和已保存的登录密码。有关联运营历史或仍在运行的环境不能删除；浏览器环境不会在此处删除。

    任务详情

    核对原订单

    根据已保存的货盘订单编号，重新读取原订单和仓库状态。此检查不会重新下单；停止调度后可以执行。

    重新排队

    只恢复这条任务的排队状态，保留原编号和执行记录。此操作不会立即执行；之后可再次检查。
    VINTED / PAGE CHECK

    核对刊登资料

    填写页面只准备表单

    按计划填写能够核对的字段，缺少的内容会列出；不会点击发布、发送消息、接受报价或提交采购。图片与网页选项仍需逐项核对。
    VINTED / ORIGINAL LISTING

    核对原刊登

    先打开原商品，再核对关联

    请在对应环境中打开这次提交的商品详情页。本次检查只读取当前活动页面；确认关联仅保存本机记录，不会再次发布或提交采购。

    点击「关联已核对刊登」即表示你确认：当前商品对应这条原发布提交。应用会记录这次操作员确认并保存本机关联。
